# Real-Time Log Monitoring and Alerting Platform

## Overview
This project demonstrates a complete observability pipeline with:
- **Linux** (scripting & environment setup)
- **Python**
- **Bash**
- **Golang**
- **Kafka**
- **Helm**
- **Kubernetes**
- **Loki**
- **Prometheus**

## Folder Structure
See `docs/architecture-diagram.png` for the system architecture.

## Quick Start
1. Run `scripts/setup_env.sh` to install dependencies.
2. Deploy everything: `scripts/deploy_all.sh`.
3. Access Grafana via port forwarding: `scripts/port_forward.sh`.
